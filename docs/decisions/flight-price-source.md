# 항공권 가격 출처

## Decisions

- 왕복 항공권 가격은 SearchApi의 Google Flights 계열 API에서 실시간으로 가져옵니다.
- 날짜별 왕복 가격은 `google_flights_calendar`(round_trip)로 한꺼번에 받고, 항공사처럼 캘린더에 없는 정보는 필요한 일정에만 `google_flights`로 따로 조회합니다.
- 가격은 원화(`currency=KRW`), 한국 시장(`gl=kr`, `hl=ko`), 성인 1명 이코노미 기준입니다.
- API 키는 저장소에 넣지 않고 git이 무시하는 환경 변수 파일로만 다룹니다.

## Boundaries

- 캘린더 요청 한 번에 담을 수 있는 출발일×귀국일 조합은 200개까지입니다. 넘으면 빈 응답이 옵니다.
- 캘린더 응답에는 항공사가 없습니다. 항공사가 필요한 일정마다 검색 1회가 더 듭니다.
- 무료 사용은 가입 시 주는 100회가 전부이고, 그다음은 유료(월 $40, 10,000회)입니다. 검색 횟수를 늘리는 동작은 이 한도를 의식해 정합니다.

## Why

`PRODUCT.md`는 보여 주는 가격이 지금 실제 가격과 맞아야 한다고 정합니다. 캘린더 API는 실시간 Google Flights 가격을 한 번에 최대 200개 날짜 조합으로 주기 때문에, 적은 호출로 월별 순위를 채울 수 있는 유일한 실시간 후보였습니다.

## Reconsider when

- 무료 횟수가 바닥나 유료 전환이 부담될 때
- 조회 기간이 다시 늘어나 순위 한 번에 드는 검색 횟수가 크게 늘어날 때
- SearchApi가 캘린더 엔진을 바꾸거나 없앨 때

## Still-rejected alternatives

- Amadeus Self-Service — 2026년 7월 17일에 종료되어 API 키가 동작하지 않습니다. Enterprise 계약은 개인 도구에 맞지 않습니다.
- Travelpayouts(Aviasales) Data API — 무료이고 항공사도 주지만, 최근 사용자 검색을 2–7일 모아 둔 캐시 가격이라 실시간 원칙과 맞지 않고 한국 출발 노선은 빠진 날짜가 있을 수 있습니다. 캐시 가격을 받아들이기로 하면 다시 봅니다.
- SerpApi Google Flights — 실시간이지만 날짜 조합마다 검색 1회가 들고 시간당 50회 제한이 있어, 61일 기간 순위 한 번에 약 122회와 2–3시간이 걸립니다. 날짜 범위를 한 번에 받는 엔진이 생기면 다시 봅니다.

## Evidence worth preserving

- 2026-10-22 PUS→KIX 확인: 출발 11/2–11/14 × 귀국 11/4–11/17(182조합) 요청에 137개 가격이 왔고, 비어 있는 조합도 있었습니다. 2–3박 일정은 26개였습니다.
- 같은 날 캘린더의 최저가(11/2–11/4, 249,400원)와 `google_flights` 상세 조회의 최저가가 일치했고, 상세 조회에서 항공사(에어부산 BX 617)를 받았습니다.
- `google_flights` 상세 결과의 `flights`에는 가는 편 구간만 들어 있습니다. 오는 편 정보는 `departure_token`으로 한 번 더 조회해야 합니다.
